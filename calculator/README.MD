Python Calculator 🧮

About the Project

This is a simple calculator built using Python. It performs basic mathematical operations based on user input.

Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Floor Division (//)
- Modulus (%)
- Power (**)

Technologies Used

- Python 3
- VS Code

How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python calculator.py

5. Enter two numbers and select an operator.
